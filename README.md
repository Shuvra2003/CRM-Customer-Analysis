# CRM Customer Segmentation & Sales Analysis

A Python-based CRM analytics project focused on customer behavior analysis, RFM-based customer segmentation, sales analysis, and interactive dashboard development.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Key Analysis

- Data cleaning and preprocessing
- Missing value handling
- Duplicate detection
- RFM analysis
- Customer segmentation
- Revenue analysis
- Product category analysis
- Acquisition channel analysis
- Customer status analysis
- Top customer analysis

## Customer Segments

- High Value
- Loyal Customers
- Potential Loyalists
- At Risk
- Low Value

## Dashboard Features

- KPI cards
- Interactive filters
- Reset filters
- Revenue visualizations
- Customer segmentation
- Top 10 customers
- Customer details table
- CSV download
- Dynamic key insights
